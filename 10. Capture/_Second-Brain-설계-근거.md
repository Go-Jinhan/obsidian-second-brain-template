# 설계 근거와 참고 문헌

이 배포본은 『세컨드 브레인』 독서 기록, 제텔카스텐 학습 기록과 실제 볼트의 운영 경험을 바탕으로 만든 템플릿이다. 아래 문헌의 원문이나 개인 독서 노트 자체는 포함하지 않는다. 모든 방법론의 유일한 정답이나 저자가 제공한 공식 템플릿을 의미하지 않는다.

## 세컨드 브레인과 CODE·PARA

티아고 포르테, 『세컨드 브레인』, 서은경 옮김, 쌤앤파커스, 2023.

| 개념 | 구현 |
|---|---|
| 4장: 공명하는 정보 수집과 열린 질문 | Capture, Feynman's Questions |
| 5장: 실행 중심 분류와 트와일라 타프의 상자 | PARA, 프로젝트 폴더, Twyla Tharp First Memo |
| 6장: 단계별 요약 | 일반 노트 앞의 Distill |
| 7장: 중간 패킷 | 프로젝트에서 다시 사용할 작은 작업물 |
| 8장: 아이디어 군도·헤밍웨이 다리·범위 축소 | Project Progress와 The Hemingway Bridge의 사용법 |
| 9장: 체크리스트와 리뷰 | 프로젝트 시작 과정, 일간·주간·월간 검토 |
| 10장: 지식 활용과 공유 | Express와 실제 결과물로 이어지는 흐름 |

Distill은 원래 노트의 맥락을 유지하며 핵심을 빠르게 읽도록 상단에 배치했다. Project Progress와 주기적 노트의 세부 제목은 볼트에 맞춘 구성이다.

## 제텔카스텐

숀케 아렌스의 『제텔카스텐』을 관련 참고 문헌으로 소개한다. 원래 볼트에는 책 링크와 별도로 임시·참고·영구 노트에 관한 학습 기록이 있다. 책 전체를 이 템플릿의 직접 근거로 검증했다고 주장하지 않는다.

이 볼트의 적용은 순간의 생각을 Fleeting에 기록하고, 외부 자료를 Reference에 출처와 함께 남기며, 독립적으로 설명할 생각을 Permanent에 작성해 연결하는 방식이다.


## 커맨드스페이스·구요한님의 지식 관리 사례에서 받은 영향

제작자의 2025년 4~5월 학습 기록에는 커맨드스페이스의 지식 관리 원칙과 구요한님의 Obsidian 활용 사례가 남아 있다. 마크다운, 메타데이터와 연결, 여러 관점으로 정보를 조직하는 방식에 관심을 두었던 사실을 확인할 수 있다.

특히 목차 연결에 관한 기록에서는 자신의 Resources에 카테고리가 많아지면 이를 활용할 수 있겠다고 해석했다. 별도의 기록에서는 topic 속성에 링크를 두거나 프로젝트·책의 중심 노트와 연결하는 방법을 탐색했다. 이는 자료를 그대로 복제하기보다 자신의 필요에 맞게 받아들이려 했던 흔적이다.

다만 **현재 Resources의 분야명과 번호 체계 전체가 커맨드스페이스에서 직접 유래했다고 확정할 자료는 확인하지 못했다.** 따라서 영향을 받은 학습 자료와 개인적으로 구성한 분류 예시를 구별한다.

참고 위치는 원래 학습 기록에 남아 있던 자료다. 이 배포본을 준비하면서 외부 영상 전체나 강의 내용을 재검증한 것은 아니다.

- 커맨드스페이스 강의 사이트: 원래 기록에 `class.cmdspace.kr`로 남아 있다.
- 구요한님의 Obsidian·AI 활용 사례 영상: 원래 기록에 `https://www.youtube.com/watch?v=_jTOW-BzfSw&t=2203s`로 남아 있다.

Resources의 번호·주제·확장 방법은 [[_Resources]]에서 설명한다.

## Obsidian에 적용한 선택

폴더는 사용할 위치, 속성은 검색과 분류, 위키링크는 노트 사이의 관계를 표현한다. Areas의 아이디어 모음을 검토 후 발전시킬 발상의 자리로 사용하는 것은 운영 제안이다.

배포본은 개인 볼트에서 발견한 경로 불일치를 정리했다. Books는 📚501. Books, 영구 노트는 31. Zettelkasten-PermanentNotes와 type: Permanent를 사용한다. 월간 노트 설정을 채웠고 Basic 선택 취소 시에도 올바른 속성 블록을 생성한다.
