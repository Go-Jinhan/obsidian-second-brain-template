# Organize — 실행할 곳을 정하기

수집한 노트를 다시 사용할 상황에 맞게 배치한다. 같은 주제의 메모라도 지금 달성할 목표가 있는지, 꾸준히 관리할 책임인지에 따라 위치가 달라진다.

| 판단 질문 | 위치 | 가상의 예시 |
|---|---|---|
| 완료 기준과 끝이 있는 진행 중인 일인가? | [[_Projects]] | 4주간 독서 기록법 실험 |
| 지속적으로 유지하고 관리할 책임인가? | [[_Areas]] | 꾸준한 독서 습관 관리 |
| 나중에 참고할 주제나 관심사인가? | [[_Resources]] | 독서법 자료 모음 |
| 지금은 진행하거나 관리하지 않는가? | [[_Archives]] | 끝난 독서 실험과 결과 |

## 정리 순서

1. 먼저 진행 중인 프로젝트에서 쓸 수 있는지 살핀다.
2. 계속 관리하는 영역과 관련이 있는지 확인한다.
3. 참고 가치가 있으면 Resources의 적절한 주제로 배치한다.
4. 비활성화된 자료는 Archives로 보관한다.

한 노트가 여러 작업에 유용하면 필요한 곳에서 링크로 참조한다. 폴더 위치와 지식 사이의 연결을 함께 사용한다.

폴더를 정했다고 생각이 완성되는 것은 아니다. 노트의 Distill을 다듬고, 새로운 생각은 영구 노트로 발전시킨다. 반대로 잘 정리된 노트도 사용할 일이 바뀌면 위치를 재검토할 수 있다.
