# Projects — 지식을 실제 작업에 쓰기

이 폴더에는 완료 기준과 끝이 있는 진행 중인 일을 둔다. 프로젝트마다 📦P-이름 폴더와 메인 노트를 두어 관련 아이디어·자료·작업물을 모은다.

## 프로젝트를 하나의 상자로 보는 이유

『세컨드 브레인』 5장에 정리된 트와일라 타프의 상자 이야기는 관련 재료를 한곳에 모으고, 시작할 때의 목표를 남기는 방법이다. 이 볼트의 프로젝트 폴더와 첫 메모는 그 철학을 적용한 구성이다. 프로젝트 메인 노트는 방향을 다시 확인하고 관련 노트를 찾아가는 출발점이다.

## Twyla Tharp First Memo — 처음의 목적을 남기기

프로젝트를 시작할 때 왜 하는지, 무엇을 이루려는지, 무엇을 알고 무엇을 모르는지 적는다. 나중에 방향이 흔들릴 때 돌아올 기준이다.

> [!example] 독서 기록법 실험의 첫 메모
> 목적: 읽은 내용을 다음 작업에 활용하는 습관 만들기.
> 완료 기준: 4주 동안 기록하고 실제로 재사용한 사례를 정리하기.
> 현재 생각: 읽은 직후 한 문장으로 설명하면 도움이 될 것 같다.
> 확인할 것: 기록에 드는 시간과 다시 찾기 쉬운 방식.

시작할 때 떠오르는 생각을 수집하고, 기존 자료를 검토·검색한 뒤, 필요한 노트를 연결하고 개요를 만든다. 이 흐름은 9장 독서 기록의 프로젝트 시작 체크리스트와 연결된다.

## Project Progress — 실행과 중간 작업물 쌓기

날짜별 진행, 할 일, 선택한 이유, 참고 자료, 실험 결과와 작업물을 기록한다. 분량이 커지면 별도 노트를 만들고 여기서 연결한다.

7장의 **중간 패킷** 관점으로 보면 조사 요약, 글의 개요, 작은 실험 결과도 나중에 다시 쓸 수 있는 작업 단위다. 다음 프로젝트에서도 활용할 수 있도록 제목과 맥락을 남긴다.

8장의 **아이디어 군도**는 관련 메모를 모아 순서를 잡고 연결하는 방식으로 활용할 수 있다. 자료 수집을 끝없이 늘리기보다, 모은 재료로 작은 결과물을 만들어본다. 일이 너무 커지면 같은 장에서 정리한 **범위 축소**를 적용해 이번에 끝낼 부분을 정한다.

## The Hemingway Bridge — 다음 작업으로 다리 놓기

작업을 멈추기 직전에 다음 항목을 남긴다.

- 지금 어디까지 했고 무엇이 남았는가?
- 아직 풀지 못한 질문이나 장애물은 무엇인가?
- 다시 시작할 때 잊기 쉬운 조건은 무엇인가?
- 다음 작업에서 먼저 할 구체적인 행동은 무엇인가?

> [!example] 오늘 작업을 멈추며
> 기록 양식 두 개를 비교했다. 작성 시간은 아직 재지 못했다.
> 다음에는 같은 글을 두 양식으로 정리하고 시간을 기록한다.
> 테스트할 때 글의 길이를 비슷하게 맞춘다.

이 항목의 핵심은 **다음 작업의 재개**다. 프로젝트가 끝났을 때만 쓰는 회고란으로 제한하지 않는다.

## 완료하고 다시 활용하기

완료 결과와 남은 일을 정리하고, 재사용할 생각은 영구 노트에 연결한다. 완료한 프로젝트는 Archives의 📦Closed-Projects에 보관할 수 있다. end_date는 예정된 종료일, finish_date를 사용하는 경우에는 실제 완료일로 구별한다.

현재 Basic 템플릿의 Project 선택과 별도 Project 템플릿 모두 위 세 제목을 생성한다. Project Progress는 이 볼트의 실행 기록 항목이다. 세 제목 전체가 책의 공식 양식이라는 의미는 아니다.
