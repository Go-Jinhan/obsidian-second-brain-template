> [!abstract] Distill(추출, 요약)
> - **책 메인 노트는 서지 정보와 독서 기록, 파생된 생각을 연결하는 출발점**이다.
> - 장별 참고 기록과 독립적인 영구 노트를 연결해 배운 내용을 다시 사용한다.

# Books — 읽은 책을 생각과 실행으로 연결하기

현재 볼트는 책마다 📓B-책 제목 폴더와 메인 노트를 두는 구조를 사용한다. TPL - Basic Note에서 Book을 선택하면 제목·독서 상태·평점 등을 입력하고 독서용 본문을 생성하도록 설계되어 있다.

## 템플릿의 구성

| 항목 | 적을 내용 | 목적 |
|---|---|---|
| 📓 책 소개 | 읽게 된 계기, 한 줄 요약 | 왜 읽었고 어떤 책인지 기억하기 |
| 🧠 핵심 생각 & 제텔카스텐 (Zettelkasten) | 장별 노트와 파생된 생각의 링크 | 책의 내용을 다른 생각으로 발전시키기 |
| 📝 책 속 핵심 문장 & 개인적 기록 | 인용과 출처, 내 반응과 적용 | 저자의 말과 내 생각을 구별해 남기기 |
| 📋 목차 | 책의 구성과 필요한 장별 기록 연결 | 내용을 찾아갈 길 만들기 |

book_title·author·status·start_date·finish_date 등의 속성은 책과 독서 상태를 찾는 단서다. 현재 Basic 템플릿의 status는 읽는 중·완독·중단·읽을 예정 선택지를 제공한다.

## 읽는 중과 읽은 뒤

장별 기록은 Reference 방식으로 작성하고, 핵심을 Distill로 추출한다. 책의 내용을 그대로 옮기기보다 자기 말로 이해한 내용과 출처를 남긴다. 적용할 일은 프로젝트에 연결하고, 독립적인 생각으로 발전한 부분은 영구 노트로 작성한다.

모든 장을 같은 분량으로 요약하거나 책 전체를 반드시 영구 노트로 바꿀 필요는 없다. 나의 질문과 실행에 필요한 내용을 중심으로 재사용한다.

배포본의 독서 노트 생성 경로는 📚501. Books에 맞추었다. 설치 방법은 [[README]]를 참고한다.
